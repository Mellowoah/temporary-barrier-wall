Setup

Lot mode: a lot = lot length from the start station (500 ft ÷ 12.5 = 40 units); every unit is assumed PASS unless you flag it. 1 station = 100 ft, so 5+00 or 500 both work.
Unit N covers start ± (N−1)×length to start ± N×length. A fail is tagged with the unit's starting station and footage.
How to run it
  1. At your start, write down the station or nearest landmark. That point is zero.
  2. Walk the wall in the direction of travel. Count footage from zero (one barrier unit is about 12.5 ft).
  3. Check every unit. Only write down units that FAIL.
  4. Take one photo per failed unit. Say the footage out loud first so photos match the log.
  5. At the end, write down your end station or landmark and text me the log.

OK vs FAIL reference
    
Pass — OK, no note needed
    
      
  • Hairline or surface cracks only
  • Small chips, no steel showing
  • Connector intact, units tight together
  • Unit sitting level and stable

    
FAIL — write it down
    
      
  • Rebar exposed (anywhere)
  • Spalling 6 in. or more
  • Crack through the unit or at the base
  • Connector damaged or missing
    • 
      
  • Base unstable, rocking, or shifted — PRIORITY, call me right away
